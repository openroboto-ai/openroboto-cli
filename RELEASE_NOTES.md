# Release Notes

## Public repository baseline

- Published the miner training entry point and isolated OpenPI runner.
- Published Hugging Face upload, evaluation-burn, and chain-announcement flow.
- Published chain commitment types and weight-setting validator logic.
- Published deterministic seed derivation from commitment block hash, subnet round, and drand randomness.
- Published miner-visible `control.json` fields and read-only API contracts.
- Linked the separate public LIBERO evaluation toolkit and baseline documentation.
- Added examples that contain placeholders only and ignore all local YAML configuration.

The scoring-service deployment, held-out task data, databases, runtime state, and owner operational tools are excluded from the public repository.
